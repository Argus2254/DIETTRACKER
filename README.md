<h1>营养智能表格使用说明</h1>

<p>一个可自定义食物库、记录每日能量、蛋白质和钠并支持多设备云同步的智能营养表格。</p>

<h2>一、功能特点</h2>

<p>自定义食物库。没有预设食物，完全由你添加，可随时修改或删除。</p>
<p>每日摄入记录。一键添加食物，自动计算总能量、蛋白质和钠。</p>
<p>日历视图。以月历形式直观查看每天的总热量摄入。</p>
<p>目标设定。自定义每日营养目标，超标自动变红提醒。</p>
<p>云同步功能。使用 JSONBin.io 实现跨设备数据同步，可选。</p>

<h2>二、使用方法</h2>

<h3>方法一，仅本地使用</h3>

<p>第一步，打开网页即可直接使用。</p>
<p>第二步，在管理食物库中添加你自己的食物，设置每份的能量、蛋白质和钠数值。</p>
<p>第三步，每日记录自动保存在你当前浏览器中。</p>
<p>注意，数据仅存在当前浏览器，换设备或清除浏览器缓存后会丢失。建议定期使用导出按钮进行备份。</p>

<h3>方法二，云端同步使用，推荐，跨设备互通。</h3>

<p>需要免费注册 JSONBin.io 账号，步骤如下。</p>

<p>第一，注册并创建 Bin。在 JSONBin.io 注册并登录，点击 Create Bin，内容填写</p>

<pre>
{
  "message": "营养数据"
}
</pre>

<p>点击 Save Bin。</p>

<p>第二，配置同步。打开营养表格网页，点击底部工具栏的同步设置按钮。勾选启用云同步，填入 Master Key 和 Bin ID，点击保存并立即同步。</p>
<p>点击左边栏 API KEYS，复制 Master Key。</p>
<p>点击左边栏 BINS，复制 Bin ID。</p>

<p>第三，跨设备使用。在手机或另一台电脑上打开同一个网页。同样进入同步设置，填入完全相同的 Key 和 Bin ID。保存后，云端数据会自动拉取到本地，实现同步。</p>

<h2>三、数据安全与隐私</h2>

<p>你的 API Key 只保存在你个人浏览器的本地存储中，不会上传到任何第三方。</p>
<p>别人即使打开同一个网页，也只能看到他们自己的数据，完全隔离，不会干扰到你的记录。</p>
<p>请勿将你的 Master Key 分享给他人。</p>

<h2>四、技术栈</h2>

<p>纯 HTML、CSS 和 JavaScript 编写，无需后端服务器。数据存储于浏览器 localStorage，云端同步使用 JSONBin.io API。</p>
